# StoryAI – The Private Writing Assistant 🖋️💻

**StoryAI** is a Python-powered automation tool designed for authors who value privacy and an efficient creative workflow.

### ✨ Key Features

* **100% Private & Offline:** Your drafts stay on your machine. No cloud, no leaks.
* **Fast Transcription:** Powered by `faster-whisper` for lightning-fast speech-to-text.
* **Aesthetic Workflow:** Integrated seamlessly into a writer's digital workspace.
